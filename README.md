# bgp_microscope

Cataloging Public BGP Archives for Correlation Analyses

## Status

**The source code will be released here once the paper is published.**

The paper was accepted and presented at IPCCC 2026, and it is now waiting for publication in the conference proceedings. The code and the visualizer are complete and ready to upload. They will appear in this repository as soon as the paper is available.

## About

BGP Microscope organizes the public BGP archives of RouteViews and RIPE RIS into a catalog of related route changes. It relates route changes across vantage points at three nested tiers (T0, T1 and T2), so that an analyst can navigate from thousands of route changes down to the few that matter. One full day of the archive is organized in under half an hour on one workstation with two consumer GPUs.

## Paper

Souvik Das and Kamil Sarac. "BGP Microscope: Navigating Public Archives for Studying Internet Routing Behavior." IEEE International Performance, Computing, and Communications Conference (IPCCC), 2026.
